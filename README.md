# StarGate

StarGate 是一个从零学习和实现的 C++ 游戏引擎项目，参考 [Piccolo](https://github.com/BoomingTech/Piccolo) 的设计逐步完善。当前使用 OpenGL，先通过小型演示掌握渲染与引擎开发的基础。

## 当前进度

- 使用 Visual Studio、CMake 和 C++20 构建。
- 接入 GLFW，创建初始尺寸为 1280 × 720 的窗口，处理窗口事件与键盘输入。
- 创建 OpenGL 3.3 核心模式上下文，通过 GLAD 加载现代 OpenGL 函数。
- 使用 VAO、VBO、顶点着色器和片段着色器，在蓝色背景上绘制彩色立方体；当前通过 `glDrawArrays` 绘制 36 个顶点组成的 12 个三角形。
- 根据顶点位置生成颜色，在顶点着色器与片段着色器之间传递并插值；目前尚未加入光照。
- 将着色器编译、链接、错误输出、绑定和资源释放整理到 `Shader` 类中，提供 `SetFloat` 和 `SetMat4` 设置 uniform。
- 接入 GLM 数学库，使用 4×4 模型矩阵组合平移、旋转和缩放，通过 `uTransform` 传入顶点着色器。
- 接入 MVP 流程，使用固定视图矩阵和透视投影矩阵；观察位置相当于 `(0, 0, 3)`，朝世界 −Z 方向观察。
- 根据帧缓冲区宽高比生成透视投影，垂直视野角为 45°，近、远裁剪面距离分别为 0.1 和 100。
- 启用深度测试，每帧清除颜色和深度缓冲，使前面的面正确遮住后面的面。
- 按住 A / D 左右平移、Q / E 调整 Y 轴旋转角度；移动距离和旋转角度根据 `deltaTime` 计算。立方体初始 Y 轴旋转角度为 30°，另有固定的 20° X 轴倾斜。
- 使用 GLFW 滚轮回调整体缩放立方体，通过窗口用户指针访问缩放变量，并限制最小缩放系数为 0.1。
- 每帧查询帧缓冲区的实际像素尺寸并设置视口，适应窗口大小变化；绘图区域为零时短暂休眠并跳过绘制，避免除零和 CPU 空转。
- 每 0.5 秒在窗口标题中更新平均 FPS 和平均帧耗时。
- 使用线程休眠进行手动限帧，目标为 60 FPS；在 Windows 上请求 1 毫秒定时器分辨率，并在退出时释放请求。
- 支持 Esc 退出，并在销毁 OpenGL 上下文前释放绘制资源。

目前完成了基础三维立方体演示、着色器封装、MVP 矩阵变换和深度测试。模型矩阵按 `T × R × S` 组合，作用于顶点时先缩放、再旋转、最后平移；顶点着色器使用 `P × V × M` 计算裁剪坐标。

当前仍使用包含重复顶点的非索引绘制。索引绘制、可移动摄像机、纹理、基础光照、模型加载、物理系统和编辑器尚未实现。

垂直同步暂时关闭，手动限帧不保证严格达到 60 FPS。窗口标题中的平均帧耗时包含限帧等待时间。

## 构建与运行

当前实现面向 Windows，需要显卡及驱动支持 OpenGL 3.3 核心模式。

1. 在 Visual Studio Installer 中安装“使用 C++ 的桌面开发”，并确认包含“用于 Windows 的 C++ CMake 工具”。
2. 克隆仓库后，在 Visual Studio 中通过“文件 → 打开 → 文件夹”打开包含 `CMakeLists.txt` 的根目录。
3. 等待 CMake 配置完成，选择 `x64 Debug` 配置和 `StarGate` 启动项。
4. 按 `Ctrl + F5` 运行，应看到蓝色背景上的彩色立方体，初始角度可看到多个面，窗口标题显示 FPS 和平均帧耗时。

| 操作 | 效果 |
| --- | --- |
| 按住 A | 向左移动立方体 |
| 按住 D | 向右移动立方体 |
| 按住 Q | 增加立方体的 Y 轴旋转角度 |
| 按住 E | 减小立方体的 Y 轴旋转角度 |
| 鼠标滚轮向上 / 向下 | 整体放大 / 缩小立方体 |
| Esc 或关闭窗口 | 退出程序 |

平移、旋转和缩放可以组合使用。滚轮缩放时请将鼠标放在窗口内；缩放系数最小为 0.1，当前未设置上限。立方体可以移出窗口，按相反方向的键可将其移回。当前输入控制的是物体变换，观察位置保持固定。

GLFW、GLAD 和 GLM 的所需文件已包含在仓库中，无需额外下载。CMake 已配置构建依赖并链接 `glfw`、`glad`、`winmm` 和 `opengl32`；GLM 使用头文件形式，通过头文件搜索目录接入。

## 目录结构

```text
StarGate/
├── CMakeLists.txt       # 构建目标和依赖
├── CMakePresets.json    # Visual Studio 构建配置
├── README.md
├── src/
│   ├── StarGate.cpp     # 程序入口、主循环、输入、MVP 和立方体绘制
│   ├── StarGate.h       # 预留项目头文件，当前未使用
│   ├── Shader.h        # 着色器类声明与 uniform 设置接口
│   └── Shader.cpp      # 着色器编译、链接和资源管理
└── third_party/
    ├── glfw/            # GLFW 源码
    ├── glad/            # 生成的 OpenGL 3.3 Core 加载代码
    │   ├── include/
    │   └── src/gl.c
    └── glm/             # GLM 数学库与许可说明
        ├── copying.txt
        └── glm/         # 向量、矩阵和变换函数头文件
```

## 第三方依赖

- [GLFW](https://www.glfw.org/)：用于窗口、输入与 OpenGL 上下文管理。许可说明保留在 [third_party/glfw/LICENSE.md](third_party/glfw/LICENSE.md) 中。
- [GLAD](https://github.com/Dav1dde/glad)：用于加载现代 OpenGL 函数。当前生成配置为 OpenGL 3.3 Core，文件位于 `third_party/glad`。
- [GLM](https://github.com/g-truc/glm)：用于向量、矩阵和变换计算，当前使用头文件形式。许可说明保留在 [third_party/glm/copying.txt](third_party/glm/copying.txt) 中。
